| 就业协议书（三方协议） |  |
| 三方上的毕业时间怎么填？ | 写2026（答辩的年份） |
| 三方的内容如何填写？ | 与单位协商一致填写即可，无具体要求 |
| 纸质三方签约流程 | 2026届三方协议已发放到学校，还未领取的同学可在工作时间到B223助管同学处领取，   延毕的同学请先变更就业年份到答辩年份，凭证材料上传offer（同济就业网 [tj91.tongji.edu.cn](https://tj91.tongji.edu.cn/)） 1. 个人和用人单位在三方上签字、盖章。   2. 同济就业网（[tj91.tongji.edu.cn](https://tj91.tongji.edu.cn/)）登记毕业去向，类别选“派遣”！（选调生选“国家地方项目”，公务员选“派遣”），最下方凭证材料处上传单位已盖章的三方扫描件。（无需等待审核）   3. B223助管处盖章（寒暑假期间不需要）   4. B218盖学院章（寒暑假期间不需要）   5. 学校就业中心（经纬楼101）盖学校章，学校会收走一联三方，其余自己保管。 |
| 网签三方与签纸质版三方有什么区别？ | 网签三方最后仍需导出、打印盖章，只是少了一步领取纸质三方的程序。 |
| 网签三方流程 | 流程说明：https://tj91.tongji.edu.cn/frontpage/tongji/html/newsDetail.html?id=c1b92b93130dff855971eb54868f0764 1. 网上生成三方协议后，导出打印，个人和企业签字、盖章。   2. 同济就业网（[tj91.tongji.edu.cn](https://tj91.tongji.edu.cn/)）登记毕业去向，类别选“派遣”！（选调生选“国家地方项目”，公务员选“派遣”），最下方凭证材料处上传单位已盖章的三方扫描件。（无需等待审核）   3. B223助管处盖章（寒暑假不需要）   4. B218盖章（寒暑假不需要）   5. 学校就业中心（经纬楼101）盖学校章，学校会收走一联三方，其余自己保管。     网签，单位必须注册信息登记号，注册网址：http://www3.firstjob.shec.edu.cn/pros/identity/yrdw.action） |
| 解约流程 | 如与原单位为网签，则自行与单位在系统发起解约即可。    如与原单位签的纸质版，请根据下方流程操作：   1.原单位提供的解约证明（无模板，说明情况即可，盖公章）   2.新单位录用函（邮件、公示截图等）   3.原三方（自己手里那份）   4.《就业协议书申领表》（同济就业网下载，服务指南-资料下载）   5.携带以上材料至研工办B223盖章，再到就业中心办理解约，领取新三方或直接网签。（每个工作日都可办理，如材料齐全，可当天办理完毕）     注意：解约需赔付违约金，考上公务员选调生并非一定可以免赔付，以三方协议签约内容为准，具体请与公司协商。 |
| 三方上学校还未盖章，能否不提供单位解约证明？ | 自毕业生与用人单位签字盖章起，双方协议关系即成立，协议书具有法律效力。因故解除协议的，属于违约，需提供解约证明。 |
| 三方内容填写错了怎么办？ | 1.单位信息部分有错，请划掉修改，单位在涂改处盖公章，以示修正。   2.学生信息部分填写错，请划掉修改，到就业中心盖修正章（经纬楼101）。 |
