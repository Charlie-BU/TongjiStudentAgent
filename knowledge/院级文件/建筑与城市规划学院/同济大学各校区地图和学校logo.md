# 同济大学各校区地图和学校logo

详见学校网址：https://photo.tongji.edu.cn/zt/tjLOGOyxydt.htm

| **建筑名称** | **位置** | **简介** |
|---|---|---|
| **南北楼** | 四平路校园大门正对的南北位 | 同济的教学楼一南一北，称为南楼和北楼。建于20世纪50年代，至今仍是大部分同济人上课的地方。 |
| **瑞安楼** | 图书馆的西侧，位于图书馆与大礼堂之间 | 瑞安楼是全国首座落成的研究生专用教学设施。现也用作新生院的办公楼。包括各类教学和办公用房。中庭有很高的利用率，可以用作展览、庆典、集会等。 |
| **图书馆** | 四平路校门正对 | 1934年正式建立同济大学图书馆。经过多次的搬迁与重建，至1990年建成现在的四平路校区图书馆（扩建后面积22225平方米）。 |
| **德文图书馆** | 中德大楼1-2楼近南校区门 | 德文图书馆，面积近3000平方米，包括阅览室、研习室、报告厅、影音室等阅读和休闲空间。 |
| **衷和楼** | 校园的东北角 | 衷和楼是一幢集教学、科研、办公等多项功能于一体的综合性建筑，也是全国高校钢结构第一高楼。 |
| **大礼堂** | 靠近校园西侧 | 大礼堂建成于1962年，建筑面积3600平方米。该建筑曾获“新中国 50 年上海经典建筑”提名奖，为上海市第四批优秀历史建筑名单。 |
| **中法中心** | 校园的西南角 | 同济大学中法中心是是中法双方合作开展教学科研，举行文化、艺术、科技交流活动的绝佳场所。 |
| **经纬楼** | 大礼堂东南侧，中央大草坪北侧 | 经纬楼是汇聚展览、学术交流、会议、休闲活动和公共社交等功能的具有现代艺术气息的综合活动中心。 |
| **大学生** **活动中心** | 经纬楼旁 | 大学生活动中心是一个为各项学生议、社交活动、学生工作提供场所的综合性建筑。校团委、校学生会等组织都在大学生活动中心内开展日常的工作。 |
| **运筹楼** | 校园西北角，近国康路校门 | 运筹楼，原是同济大学经济与管理学院大楼，现改为中意可持续发展中心。 |
| **创业谷** | 129礼堂北侧 | 同济大学创业谷是校内建设的一个“讲述创业故事、分享创业经验、畅谈创业感悟、汇集创业力量”的大学生创业实践平台。 |
| **“一·二九”大楼** | 校园大门的南侧 | 同济大学“一· 二九”大楼建于1942年，为纪念“一· 二 九” 学生运动，此建筑群更名为“一·二九” 大楼。该大楼东侧为“一·二九”礼堂 ，平时主要用作小会堂并兼顾放映和小型演出。 |
| **逸夫楼** | 学校正门内中心主干道南侧 | 同济大学逸夫楼，又名科学苑。作为同济大学的学术交流中心，是举办高水准的中小型国际、国内会议的场所，具备现代化设施的教学中心。 |
| **旭日楼** | 学校正门内中心主干道南侧，逸夫楼旁 | 旭日楼自2015年重新改造正式作为“校友之家”。其主要功能是为校友返校交流和学习、校友文化展示、学校重要礼仪接待提供场所和服务。 |
